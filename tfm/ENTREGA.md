# Lista de entrega del TFM

Basada en el texto de requisitos que el alumno compartió en «Crear agente de IA vendible». El fragmento no contiene rúbrica ponderada ni plazo exacto de entrega. La fecha oficial debe comprobarse en el temario.

## Material preparado

- README con descripción, tecnologías, instalación, estructura, funciones y enlaces.
- Arquitectura, límites y decisiones técnicas.
- Accesos ficticios reproducibles en una demostración aislada.
- Pruebas y evidencia de ejecución.
- Presentación editable ORQENTIVA-TFM.pptx.
- Guion del vídeo, recorrido de pantalla y preguntas de práctica.
- Información del estado de despliegue.

## Datos que el alumno debe completar

| Campo del formulario | Estado |
| --- | --- |
| Nombre completo | Confirmar nombre exactamente como en la matrícula |
| Correo de inscripción | Introducir el correo utilizado en el máster |
| URL de GitHub | Pendiente: no había remoto configurado al revisar |
| URL de despliegue | No existe, recomendado si es viable |
| URL de las slides | Publicar la presentación o usar un enlace al archivo accesible del repositorio |
| URL del vídeo | Grabar y subir con acceso público por enlace |
| Usuario y contraseña de prueba | Preparados para la demo local, ver ACCESO_DEMO.md |

## Acciones del alumno

1. Leer el guion, verificar su nombre y adaptar las explicaciones a sus propias palabras.
2. Revisar el material y realizar el commit manual en VS Code. Mensaje sugerido: «preparar evaluación y entregables del TFM con demostración aislada».
3. Elegir la visibilidad de GitHub. El texto pide repositorio público. Un privado requiere justificación y acceso al evaluador indicado en las instrucciones originales. No se ha concedido acceso a terceros.
4. Publicar el código y comprobar acceso sin sesión. Se preparará el enlace cuando exista el repositorio; no hay una URL inventada.
5. Grabar la explicación con captura de pantalla. Mostrar el rostro es opcional. El texto compartido no fija duración obligatoria.
6. Publicar el vídeo y completar enlaces reales en README y este documento. Si se desea despliegue, acordar destino y presupuesto antes de contratar.
7. Abrir el formulario oficial desde la lección del Proyecto Final, completar los campos y enviar personalmente.

Antes del envío: comprobar los enlaces en una ventana privada, confirmar que el vídeo se ve y se oye, que las slides se abren y que las instrucciones permiten arrancar la demo. El paquete preparado no implica que el TFM haya sido enviado ni garantiza una calificación.
